# Koba-PC16bits-Juego

## Minijuego: Donkey Kong

Integrantes: Leandro Caraballo; Antonio Gomez; Facundo Naveira; Luca Mamani

El juego consiste en rescatar a una chica que fue secuestrada por un gorila gigante, Donkey Kong.

Para lograrlo, controlamos a un hombre que tiene que ir subiendo por una serie de plataformas y estructuras tipo construcción. A medida que subimos, el gorila te va tirando barriles y otros obstáculos que tenemos que ir esquivando o saltando para que no nos mate. También aparecen unos fuegos tipo enemigos que te persiguen y, a veces, podemos agarrar un martillo para destruirlos y limpiar un poco el camino.

El objetivo principal es llegar hasta arriba de todo para salvar a la chica. Hay distintos niveles; en algunos tenemos que simplemente escalar esquivando los barriles, y en otros tenemos que ir sacando como unos pernos o tornillos de las plataformas para hacer que la estructura se caiga, tirar al gorila y así ganar la pantalla. Una vez que lo logramos, el juego vuelve a empezar pero con una dificultad mucho más alta, donde todo se mueve más rápido y se vuelve bastante caótico.
